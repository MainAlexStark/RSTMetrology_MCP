# ФГИС «Аршин»: что известно об API

Сервер ходит в официальный публичный интерфейс ФГИС ОЕИ «Аршин» Росстандарта:
`https://fgis.gost.ru/fundmetrology/eapi` (руководство «Внешние публичные интерфейсы» v2.2).
Ключ не нужен. Тестовый стенд Росстандарта — `https://fgis.gost.ru/fundmetrologytest/eapi`
(задаётся через `RST_BASE_URL`).

## Эндпоинты

| Метод | Что отдаёт |
|---|---|
| `GET /vri` | список записей о поверке |
| `GET /vri/{vri_id}` | карточка поверки |
| `GET /mit` | список утверждённых типов СИ |
| `GET /mit/{mit_uuid}` | карточка типа |

Ответы обёрнуты в `{"result": …}` (кроме карточки типа); списки — `{"count", "start", "rows", "items": […]}`.

### Список поверок — параметры

`search`, `mit_number`, `mit_title`, `mit_notation`, `mi_modification`, `mi_number`, `org_title`,
`year`, `verification_date_start`, `verification_date_end`, `applicability`, `sort`, `rows` (≤100), `start`.
Имена фильтров совпадают с именами полей ответа. Неизвестный параметр — HTTP 400
`{"message": "Параметр X не допустим для запроса"}`.

Строковые фильтры: совпадение с целым словом без учёта регистра, `*` и `?` — шаблон
(`*бетар*` — по подстроке), несколько слов через пробел — ИЛИ (и в `search`, и в поле;
`AND`, `+` не работают). `search` ищет по всем полям записи.

### Список типов — параметры

`search`, `title`, `notation`, `manufacturers`, `rows`, `start` (`manufacturer` — 400).
Строка: `mit_uuid`, `number`, `title`, `notation`, `manufacturers`.

### Карточка типа — форма

Без обёртки `result`:

```json
{"general": {"mit_uuid": "…", "number": "16078-05", "title": "…", "notation": ["…"],
             "valid_to": "2015-01-01", "production_type": "1"},
 "mpi": [{"parameter": "для хол. воды", "mpi": 72, "valid_from": "2005-01-01"}],
 "spec": [{"doc_url": "…/eapi/doc/<uuid>"}],
 "manufacturer": [{"title": "…", "country": "РОССИЯ", "address": "…"}]}
```

`mpi` — межповерочный интервал в месяцах, может быть несколько (по параметрам);
`valid_to` — срок действия свидетельства об утверждении типа.

### Карточка поверки — форма

```json
{"result": {
  "publication": {"status": "Запись модифицирована", "vriVerIdNext": "1-…"},
  "miInfo": {"singleMI": {"mitypeNumber": "…", "mitypeURL": "…/cm/mits/<uuid>",
             "mitypeType": "…", "mitypeTitle": "…", "manufactureNum": "…",
             "manufactureYear": 2014, "modification": "…"}},
  "vriInfo": {"organization": "…", "signCipher": "…", "miOwner": "…",
              "vrfDate": "dd.mm.yyyy", "validDate": "dd.mm.yyyy", "vriType": "2",
              "docTitle": "МИ 1592-2015",
              "applicable": {"certNum": "С-…", "signPass": true, "signMi": false}}
}}
```

- прибор бывает под `singleMI` (единичное СИ), `etaMI` (эталон) или `partyMI` (партия), иногда в корне `result`;
- непригодность — ключ `inapplicable: {"noticeNum": "И-…"}` вместо `applicable`;
- `publication` есть только у модифицированных или аннулированных записей.

## Поведение, на котором легко споткнуться

- **Только российские адреса.** Снаружи соединение висит до таймаута.
- **2 запроса в секунду с адреса.** Сверх — 429, при упорстве — блокировка адреса. Клиент держит паузу 600 мс между любыми запросами процесса (`RST_MIN_INTERVAL_MS`) и повторяет на 429/5xx с учётом `Retry-After`.
- **Без `year` / `verification_date_start` поиск идёт только по текущему году.**
- **Широкий запрос — 400 или 408** («превышен лимит на поиск»).
- **Даты в двух форматах**: `14.11.2023` и `2023-11-14`. Наружу сервер отдаёт ISO.
- **HTML вместо JSON** со статусом 200 при техработах или блокировке.
- **Заводские номера пересекаются** у разных типов СИ: один и тот же номер у счётчика воды, газа и термометра — обычное дело.

## Что не проверено вживую

Код написан по документации и наблюдениям работающих интеграций; из среды разработки
ФГИС недоступна (нероссийский адрес). Перед боевым использованием:

```bash
make verify                     # или: rst-metrology-mcp --check
```

и в клиенте — `rst_selftest`. Если ФГИС назовёт параметр иначе, его можно передать через
`filters` без новой версии сервера. Меньше всего уверенности в форме ответа `/mit`
(имена полей списка типов) — поэтому он отдаётся как есть, без типизации.
